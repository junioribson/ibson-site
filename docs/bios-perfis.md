## Por que isso importa (e o que esperar, honestamente)
- Os links de LinkedIn/X para o site são **nofollow** (não passam "força" de link cru).
  O valor NÃO é PageRank, é **consolidação de entidade**: o site já aponta para esses
  perfis e para o Wikidata (sameAs no schema); os perfis apontando de volta **fecham o
  ciclo**, e é isso que o Google/IAs usam para dizer "é a mesma pessoa, e este é o site
  oficial dela".
- Ganho real: desambiguação, coerência da entidade e tráfego direto. Prazo: semanas.
