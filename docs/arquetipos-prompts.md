# Arquétipos: prompts para gerar a arte (Midjourney / Gemini / Firefly)

Objetivo: arte de fundo, editorial, hiper-realista, com textura, para entrar como
camada sutil atrás do conteúdo (opacidade baixa). Nada de vetor liso nem mascote.
Paleta da marca: creme #EBE3D1, tinta #1C0E04, roxo #44026F, violeta #5B2EE6,
dourado #B0925E, magenta #C94F8A.

Salve os arquivos gerados (de preferência PNG com fundo transparente, ou WebP) em:
- `public/assets/arquetipos/wolf-editorial.webp`
- `public/assets/arquetipos/owl-editorial.webp`
- `public/assets/arquetipos/seahorse-editorial.webp`

O site já aponta para esses caminhos: assim que os arquivos existirem, eles aparecem.

## Dicas
- Peça sempre "isolated on transparent background" e "no text".
- Prefira versões escuras/monocromáticas: entram melhor como camada de fundo.
- Se vier com fundo, me manda o arquivo que eu removo o fundo aqui.
- Para o Hero, uma arte na vertical (4:5) funciona melhor no lado direito.
