> mesma descrição de entidade que já está no schema do site (disambiguatingDescription).
> Quando LinkedIn, X e o site dizem a mesma coisa, o Google e as IAs consolidam a
> entidade "Ibson Junior" e param de confundir com homônimos (ex.: Ibson Cabral).
>
> Regra da marca: nunca usar travessão. Posicionar como executivo de conteúdo,
> liderança e comunicação (não reduzir a "estrategista digital" nem a marketing).
> Futbol Sites pode ser citada, de forma discreta. Nunca citar Better Collective.

## Por que isso importa (e o que esperar, honestamente)
- Os links de LinkedIn/X para o site são **nofollow** (não passam "força" de link cru).
  O valor NÃO é PageRank, é **consolidação de entidade**: o site já aponta para esses
  perfis (sameAs no schema); os perfis apontando de volta para o site **fecham o ciclo**,
  e é isso que o Google/IAs usam para dizer "essas contas são a mesma pessoa, e é este
  o site oficial dela".
- Ganho real: desambiguação, coerência da entidade e tráfego direto. Prazo: semanas.
