# public/assets

Estrutura pronta para receber os arquivos de imagem (nunca base64, sempre arquivo otimizado).

- `logo/`        logomarca em PNG. Esperado: `logo-roxa.png` (fundo claro) e `logo-branca.png` (fundo escuro).
- `retratos/`    fotos de retrato do Ibson. Usar só uma no Sobre (retrato navy).
- `capas/`       capas das publicações da ProliferArte em alta (quadradas, imagem inteira visível).
- `artigos/`     capas reais dos artigos do LinkedIn (não a capa dos posts).
- `arquetipos/`  imagens fotorrealistas de fundo: coruja+lua, cavalo-marinho, lobo, explorador/cosmos.

Formatos recomendados: PNG ou WebP otimizados. Nomes em minúsculas, sem espaços.
